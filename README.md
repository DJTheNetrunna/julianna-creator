# Juliana Creator Portfolio

A mobile-first creator portfolio for Juliana Aracely.

## Purpose

A curated home for selected creative projects, lifestyle content, digital experiments, and public social links without exposing unnecessary personal information.

## Social profiles

- Instagram: `@julianaaracely00`
- Facebook: linked from the website

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No build step or paid dependencies
- GitHub Pages compatible

## Local preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publishing

The site is static and can be published with GitHub Pages from the repository's `main` branch/root directory.

## Content safety

This portfolio intentionally avoids publishing school information, precise location, routines, personal phone numbers, or private contact information. Creator/business inquiries should use a parent/guardian-managed contact channel.
